# 텔레그램 '중랑AI혁신팀' 단톡방 수집

구청 네트워크에서는 web.telegram.org, api.telegram.org, telegram.org, t.me가 모두 막혀 있다(2026-10-29 확인). 그래서 정책실장이 결정한 대로(2026-10-29) **Gmail로 넘겨받는 방식이 기본**이다.

## 기본 경로. Gmail `[AX일지-단톡]` 메일

정책실장(또는 정책실장이 정한 팀원)이 단톡방 글을 골라 goodmorninghope@gmail.com 으로 보낸다. 제목은 `[AX일지-단톡]`으로 시작한다(뒤에 날짜는 있어도 없어도 된다).

1. `gmail.search(0, 'subject:"AX일지-단톡" newer_than:14d')`로 찾는다. 보낸 사람이 goodmorninghope@gmail.com 이거나 정책실장이 정한 팀원 주소인 것만 쓴다.
2. 이미 처리한 메일은 건너뛴다. 처리 여부는 이전 `[AX일지-총괄]` 발송 메일 맨 끝의 "처리한 단톡 메일:" 줄(Gmail threadId 목록)로 판단한다.
3. 메일 형태별 읽기:
   - **본문에 붙여 넣은 글**(휴대폰에서 여러 메시지를 골라 복사·공유): 글에 들어 있는 작성자와 시각을 쓴다. 시각이 없으면 본문 첫 줄의 `날짜: MM/DD`를 쓰고, 그것도 없으면 메일 보낸 날을 쓰되 "날짜 확인 필요"를 붙인다.
   - **텔레그램 PC 앱 "대화 내보내기" 첨부**(result.json, messages.html, 또는 그 zip): `gmail.downloadAttachment`로 받아 읽는다. 지난 실행 이후(처음이면 받은 파일 전체 중 최근 14일) 메시지만 본다.
   - **사진만 있는 메일**: 일지 반영 없이 "사진 후보: MM/DD 무엇"만 적는다.
4. 이번 실행에서 처리한 메일의 threadId를 `[AX일지-총괄]` 메일 맨 끝 "처리한 단톡 메일:" 줄에 적는다. 단톡 메일이 없으면 T절에 "오늘 [AX일지-단톡] 메일 없음"이라고 적는다.

## 보조 경로. 텔레그램 웹 (텔레그램이 열리는 네트워크일 때만)

`openTab('https://web.telegram.org/a/')`가 20초 안에 열리고 로그인돼 있으면 '중랑AI혁신팀' 방에서 지난 실행 이후 메시지를 읽는다. 열리지 않거나 QR 로그인 화면이면 조용히 건너뛴다(로그인 시도 금지). 메시지를 보내거나 반응·고정·삭제하지 않는다. Gmail 경로와 겹친 글은 한 번만 올린다.

## 거르기 규칙

- 올리는 것: 실제로 일어난 업무 사실. 회의·보고·결정, 제작·배포(문서·영상·포스터·도구), 외부 연락의 결과, 교육·특강·방문, 막힌 일과 되돌린 일(고비 후보).
- `#일지` 태그 글은 T-확정, 나머지 업무 사실은 T-후보로 나눈다.
- 빼는 것: 잡담·인사·식사 약속, 개인 일정, 민원인·주민 개인정보, 인사·평가·보안 논의, 외부 업체 견적·내부 의견(예: 업무 도구 보안 검토), `[비공개]`·`#비공개` 글. 뺀 글은 내용 없이 건수만 센다.
- 사진·영상·첨부 파일 본문은 일지에 자동으로 들어가지 않는다. 일지에 어울리는 사진이 있으면 "사진 후보: MM/DD 무엇(작성자)"만 적는다.
- 작성자는 이름만 적고 연락처·아이디는 적지 않는다.
- 날짜는 메시지가 올라온 날이 아니라 일이 일어난 날을 쓴다. 분명하지 않으면 "날짜 확인 필요"를 붙인다.
