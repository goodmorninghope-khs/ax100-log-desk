# GPT 개선의견 (2026-10-29)

ChatGPT 대화 「개선의견 정리」 https://chatgpt.com/c/6ae2c6f1-fdd4-83ee-b68c-4a055367ef48 에 일지 페이지 전체 텍스트(27일차까지)를 넘겨 받은 의견의 요지다. GPT 제안이며 정책실장 승인 전이다.

핵심: "한 일"과 "바뀐 일", "확인된 사실"과 "AI의 해석"을 나눈다.

1. 기록 구조: 하루가 아니라 사건 단위로 분류. 유형(실행·배움·고비, 복수)과 상태(제안→결정→착수→완료→검증 / 보류·중단)를 분리. "고비 0"은 "확인된 고비 0"으로. 빈 날은 미기록·활동 없음·미래로 구분. 출범 전 준비는 따로 표시.
2. 정보 위계: 맨 위 상황판(D-day, 기록 일수, 최근 기록, 핵심 변화, 막힌 일, 다음 결정). 순서는 상황판→100일 목표→최근 기록→숨은 실. 일별 카드는 3줄(한 일 / 달라진 점 / 다음 확인). AX와 관계가 불분명한 일정은 보조로.
3. 성과 측정: 목표마다 책임자·기한·완료 조건·증거·상태. "바뀐 일"에 고유번호. 산출물과 변화량 분리. 비교값이 없으면 "측정 전".
4. 출처 신뢰성: 출처를 문장마다. 캘린더만 있으면 "예정". "소회 기다림"을 "사실: 미확인 / 소회: 미작성"으로. 날짜 충돌 점검(예: 숨은 실 '대신 하지 않고 곁에서'는 D7~D22 표기인데 본문에 10/24 포함, 화면에서 확인됨).
5. 연재 활용: 숨은 실은 "연결 가설"로 표시. 회차마다 빠진 재료(장면·갈등·선택·결과·발언) 표시. 기록 하나는 주회차 1개 + 보조회차 최대 2개. "꼴찌"·"아낀 돈"은 근거 전까지 가제.
6. GPT 역할: 주간 대조, 이행 추적, 근거 보완, 소회 질문. 전달 형식은 신규 사실 / 정정 / 확인 필요 / 연결 가설.

우선 수정 5가지: ① 미기록 상태 구분 ② 사건별 진행 상태 ③ 문장별 출처 ④ 목표별 완료 조건 ⑤ 숨은 실 "연결 가설" 표시.
