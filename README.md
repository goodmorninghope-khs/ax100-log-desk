# ax100-log-desk · 중랑AX2030 100일 일지 총괄 데스크

중랑구 AI혁신팀의 「중랑AX2030 100일 일지」(2026-10-01 ~ 2027-01-08, https://claude.ai/artifact/Jxz2t6Cwiwjsjihk9gv8eV)를 세 AI가 나눠 운영하는 스킬이다.

| 누구 | 역할 |
|-|-|
| Aside | 총괄 데스크. 매일 21:30 네이버 공유 캘린더·텔레그램 '중랑AI혁신팀' 단톡방을 모아 거르고, 전날 반영을 점검하고, 일요일엔 GPT 대조를 받아 `[AX일지-총괄]` 메일로 넘긴다 |
| Claude | 집필. 매일 21:52 예약 작업이 일지 DB에 쓴다(유일한 쓰기 담당) |
| GPT | 검증관. 주 1회 정정·확인 필요·이행 추적·연결 가설·소회 질문·고비 후보 |
| 정책실장 | 소회, 숨은 실 확정, 공개 판단 |

## 연계 (밸류체인)

이 저장소는 [policy-media-desk](https://github.com/goodmorninghope-khs/policy-media-desk) 밸류체인의 **① 원료 · ⑦ 되먹임** 고리다. 상태: 제안 (발행인 확인 후 실제로 이으면 '연계'로 바꾼다).

- 받음: WEEKLY AX 신호 → 일지 '연결 가설' 후보
- 넘김: AI혁신팀이 이미 한 일(일지·업무기록) → 지면 '중랑이 이미 하고 있는 일' 근거(jungnang-signal shared/reference-hub.md)
- 넘길 때는 출처 지면(지면명·호수·날짜·링크)과 '닿는 공약'을 붙이고, 침은 의견으로 남긴다. 결정은 받는 고리의 책임자가 한다.
